## 2. 타겟 사용자 (페르소나 2명)

### 페르소나 A — 사회초년생 "김지수" (27세, 직장인 2년차)
- 목돈을 모아본 적이 없고 "적금이 복리인지 단리인지"도 헷갈린다.
- 목표: 3년 안에 전세 보증금 일부(예: 5천만원)를 만들고 싶다.
- 니즈: 어려운 금융 용어 없이, 지금 매달 얼마씩 넣어야 하는지 감을 잡고 싶다.

### 페르소나 B — 30대 맞벌이 "박현우" (34세)
- 예/적금과 소액 투자를 병행 중이며 은퇴 자금 계획을 세우고 싶어한다.
- 목표: 65세까지 은퇴자금 5억원을 모으고 싶고, 수익률별 시나리오를 비교하고 싶다.
- 니즈: 수익률·복리 주기를 바꿔가며 결과를 빠르게 비교하고, 지금 페이스가 목표에 충분한지 진단받고 싶다.

## 3. 페이지 구성과 이동 방식

공통 네비게이션(상단 고정, 모바일은 햄버거 메뉴)으로 4개 페이지를 이동한다. 현재 페이지는 `aria-current="page"`로 표시된다.

| 페이지 | 파일 | 핵심 내용 |
|---|---|---|
| 홈 / 계산기 | `index.html` | Hero, 복리 계산기 입력 폼, 결과 요약 리스트(최종 평가금액 강조 + 4개 지표), 연도별 SVG 그래프, 연도별 표, AI 투자 코치 |
| 복리 알아보기 | `learn.html` | 복리 정의(단리 대비), 계산기 사용법, 계산 공식, 복리의 중요성(72의 법칙 등) |
| FAQ | `faq.html` | 아코디언 UI, 13개 문항, 실시간 검색 필터 |
| 문의하기 | `contact.html` | 이름/이메일/유형/내용 폼 → Discord 웹훅 연동(보너스) |

## 4. 핵심 기능 정의

1. **복리 계산기**: 초기 금액, 월 적립액, 투자 기간(일/월/년), 목표 수익률, 복리 주기(연/월/일)를 입력받아 즉시 프론트엔드에서 계산(`js/calculator.js`).
2. **결과 시각화**: 요약 카드(카운트업 애니메이션), 반응형 SVG 영역 차트(`js/chart.js`), 연도별 상세 표, CSV 내보내기, URL 쿼리스트링 공유, 결과 이미지 저장·공유(`js/share.js`, Canvas 2D로 브랜드 카드 PNG 생성 후 다운로드 또는 Web Share API 연동).
3. **AI 투자 코치** (AI 기능): 계산 결과 + 사용자의 목표 문장을 받아, 목표 달성 가능성 진단·부족분 해석·실행 조언 3가지·주의사항을 반환.
4. **문의하기(보너스)**: 문의 폼 제출 시 Discord 웹훅으로 운영자에게 알림.
5. **다크 모드 / 마이크로 인터랙션(보너스)**: 시스템 설정 자동 감지 + 수동 토글, 카운트업·그래프 드로잉·아코디언·로딩 스켈레톤 애니메이션.

## 5. AI 기능 — 입력 / 출력 / 실패 처리 기준

| 항목 | 내용 |
|---|---|
| 엔드포인트 | `POST /api/coach` (Vercel Python Serverless Function, `api/coach.py`) |
| 입력 | 계산 결과값(초기금액·월적립액·기간·수익률·복리주기·최종금액·총원금·총이자·수익률) + 사용자 목표 텍스트(최대 300자) |
| 출력 | `{ diagnosis, gap, actions: [3개], caution }` 형태의 JSON. 화면에는 마크다운을 그대로 뿌리지 않고 카드 UI로 파싱해 표시 |
| 사용자 가치 | 숫자만 보여주는 계산기를 "그래서 나는 무엇을 해야 하는가"까지 답하는 서비스로 확장 |

### 실패 처리 3종

| 상황 | 감지 위치 | 사용자 안내 |
|---|---|---|
| 빈 입력 / 필수값 누락 | 프론트(`js/ai.js`), 요청 전 차단 | "목표를 한 줄이라도 입력해 주세요." 인라인 메시지, textarea 포커스 |
| API 오류 (4xx/5xx) | 백엔드 상태코드 → 프론트 분기 | 429 → "요청이 많습니다. 잠시 후 다시 시도해 주세요.", 5xx → "일시적인 오류입니다.", 재시도 버튼 노출 |
| 지연 / 타임아웃 | 프론트 `AbortController` 25초 | 로딩 스켈레톤 + 경과 시간 표시, 초과 시 "응답이 지연되고 있어요. 다시 시도해 주세요." |

### 과금·쿼터 방어 정책
- 클라이언트: 요청 완료 후 10초 쿨다운(버튼 비활성 + 카운트다운)
- 서버: 목표 텍스트 300자 초과 거부(400), 요청 본문 8,000바이트 초과 거부(400)
- AI 응답 `max_tokens`(Gemini `maxOutputTokens`) 700으로 상한
